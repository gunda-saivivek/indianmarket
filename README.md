# 🚀 Indian Market Pulse Pro

Live Equal CE/PE & Hero-Zero Trade Intelligence Engine for **NIFTY 50**, **SENSEX**, and **BANK NIFTY**.

---

## 🌟 Key Features

1. **🎯 What to Buy Now (Automated Strategy Engine):**
   - Automatically determines market bias using PCR (Put-Call Ratio) and intraday range.
   - Recommends the #1 Call (CE) and Put (PE) strike with exact entry price, TradingView spot trigger level, and risk-reward targets.

2. **⚖️ Equal CE & PE Pairs Matcher:**
   - Pairs strikes where Call and Put premiums are balanced (e.g. ₹20 CE with ₹20 PE, ₹50 CE with ₹50 PE, or ATM straddles).
   - Perfect for breakout trades: winning side explodes 2x–3x while risk is capped strictly at entry cost.

3. **🎯 Hero-Zero Hotlist (₹10 - ₹35 Sweet Spot):**
   - Live curated list of high-gamma expiry day strikes for explosive moves.

4. **⚡ Real-Time Live Market Feed:**
   - Continuous ticks with flashing green/red indicators.
   - Zero login required to stream market data.

5. **🔍 "Why Buy?" Trade Decision Engine:**
   - Click any strike to view deep trade rationale, TradingView trigger price, delta expansion analysis, and capital calculator.
   - One-click copy string for Upstox / broker search bar.

## 🛠️ Quick Start Locally

### Prerequisites
- Node.js (v18+)

### Run
```bash
git clone https://github.com/gunda-saivivek/indianmarket.git
cd indianmarket
npm start
```
Open **`http://localhost:7171`** in your browser.

## ☁️ Deploy Free 24/7 (Render / Railway)

1. Log in to [Render.com](https://render.com).
2. Click **New +** -> **Web Service**.
3. Select this GitHub repository: `https://github.com/gunda-saivivek/indianmarket.git`.
4. Build Command: `npm install` (or leave blank).
5. Start Command: `npm start`.
6. Click **Create Web Service** — Render will give you a free, public 24/7 web link!
